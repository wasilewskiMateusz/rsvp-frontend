# Zdjęcia na stronę wesela

## Wymagane zdjęcia:

1. **hero-photo.jpg** (1920x1080 min)
   - Duże zdjęcie tła na górze strony
   - Najlepiej poziome zdjęcie pary w pełnej rozdzielczości

2. **couple-round.jpg** (500x500)
   - Okrągłe zdjęcie pary do sekcji zaproszenia
   - Kwadratowe, zostanie przycięte do koła

3. **story-photo.jpg** (800x600 min)
   - Zdjęcie do sekcji "Nasza Historia"
   - Może być pionowe lub poziome

4. **gallery/** (folder)
   - Wrzuć tutaj wszystkie zdjęcia do galerii
   - Nazwij je: photo1.jpg, photo2.jpg, photo3.jpg...
   - Maksymalnie 2MB na zdjęcie

## Wskazówki:

- Format: JPG lub PNG
- Używaj zdjęć wysokiej jakości
- Zoptymalizuj zdjęcia przed wrzuceniem (np. na tinypng.com)
- Unikaj polskich znaków w nazwach plików
